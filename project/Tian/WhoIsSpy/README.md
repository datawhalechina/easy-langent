# WhoIsSpy — LangGraph 多智能体「谁是卧底」游戏

## 项目简介

基于 LangGraph 构建的多智能体回合制推理游戏。3 位 AI Agent + 1 位人类玩家共同参与经典的"谁是卧底"桌游：系统自动生成相似词语对、分配角色身份，AI Agent 根据历史发言动态调整策略进行描述与投票，人类玩家通过命令行与 AI 同台博弈，直至卧底被找出或平民全部出局。

## 核心功能

| 功能模块 | 说明 |
|----------|------|
| **词语生成** | LLM 自动生成高相似度的平民词/卧底词对（如"奶茶-果汁"），AI 生成失败时自动回退到预设词库 |
| **角色分配** | 4 名玩家（agent1、agent2、user、agent3）中随机指定 1 人为卧底，其余为平民 |
| **多轮发言** | AI Agent 结合历史发言记忆动态调整策略：平民找矛盾、卧底模仿平民避免暴露 |
| **投票淘汰** | 每轮发言后全员投票，基于当前轮+历史发言分析矛盾点，用户通过命令行投票 |
| **胜负判断** | 自动判定：卧底被淘汰 → 平民胜；剩余 1 平民 + 1 卧底 → 卧底胜；支持平票处理 |
| **人机交互** | 用户通过命令行输入发言内容、选择投票目标，实时查看 AI 推理过程 |

## 代码运行步骤

### 1. 配置 API 密钥

编辑项目根目录下的 `.env` 文件，填入智谱 API 密钥（游戏使用智谱 GLM-5.2 模型）：

```env
ZHIPU_API_KEY="你的智谱API密钥"
ZHIPU_BASE_URL="https://open.bigmodel.cn/api/paas/v4/"
```

### 2. 安装依赖

```bash
cd easy-langent
uv sync
```

### 3. 运行游戏

```bash
uv run python WhoIsSpy.py
```

### 4. 游戏流程

```
生成词语 → 角色分配 → 显示你的身份和词语
    ↓
┌─→ 第 N 轮发言（AI 依次发言 → 轮到你输入发言）
│       ↓
│   投票淘汰（AI 投票 → 你选择投票目标）
│       ↓
│   胜负判断 ──→ 游戏继续 ──┘
│       ↓
│   游戏结束 → 展示结果
└──────┘
```

**你的交互节点：**
- **发言阶段**：看到「【你的回合】」提示后，输入描述词语的发言（10-100 字）
- **投票阶段**：看到「【你的投票回合】」提示后，输入要淘汰的玩家名（agent1/agent2/agent3）

### 5. 示例玩法

```
角色分配完成：
🎭 你的角色是【平民】，你拿到的词语是：【奶茶】

第1轮发言阶段：
>>> agent1: 这是一种日常饮用的饮品，有多种口味可选...
>>> agent2: 这个饮品冷热都可以喝，街边很多店铺在卖...
【你的回合】你的角色：平民，你的词语：奶茶
请输入你的发言：喝起来甜甜的，经常和珍珠或者椰果搭配

第1轮投票阶段：
>>> agent1: 投票给 agent3，理由：描述太过模糊...
>>> agent2: 投票给 agent3，理由：回避核心特征...
【你的投票回合】当前存活玩家：['agent1', 'agent2', 'agent3']
请输入你要投票淘汰的玩家名：agent3
```
